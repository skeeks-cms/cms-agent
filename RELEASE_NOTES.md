# 3.1.0.2

- Необязательная интеграция с skeeks/cms-job: постановка задания по расписанию
  вместо прямого исполнения консольной команды.
- Настройка jobType/jobPayload в конфигурации команды и полях агента.
- Ручной запуск, состояние задания, карточка расписания и связанная история
  через стандартные backend actions.
- Человекочитаемый интервал расписания.

Перед использованием применить миграцию
`m260822_220000__alter_table__cms_agent__job_type` через `php yii cms/migrate`.
Миграция нужна и проектам без cms-job. Выполнять до возобновления расписания.
Для очередей установить cms-job 1.0.0 и настроить обслуживание нужных полос.
Без компонента jobs сохраняется прямой запуск команд.

Проверены PHP-синтаксис и интеграционный мост в регрессионном прогоне cms-job
на отдельной БД. Выкладка и миграции боевых проектов этим релизом не выполняются.
